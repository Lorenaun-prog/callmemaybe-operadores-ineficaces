# 📞 Identificación de Operadores Ineficaces — CallMeMaybe

Nota: Proyecto del programa Data Analyst, con datos de un caso práctico.

## 📌 Contexto

CallMeMaybe, un servicio de telefonía virtual, quiere identificar operadores ineficaces basándose en métricas de desempeño, llamadas perdidas y tiempos de espera.

## 🔎 Objetivos

Analizar los datos históricos de llamadas (entrantes, salientes e internas).

Identificar operadores con bajo desempeño y posibles ineficiencias.

Evaluar hipótesis estadísticas sobre diferencias entre operadores.

Generar recomendaciones para mejorar la productividad y eficiencia del equipo.

## 📂 Datasets

telecom_dataset_us.csv → registro de llamadas: dirección, operador, llamadas perdidas, duración.

telecom_clients_us.csv → información de clientes: ID, plan tarifario, fecha de inicio.

## 🛠️ Tecnologías

Python · pandas · numpy · matplotlib · seaborn · scipy · Jupyter Notebook
